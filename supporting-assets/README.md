# Supporting assets

These print files are for **Operation Howell Creek**. Use one badge per agent for the SNAVE Estates briefing and one control box per team for the rogue processor challenge at the pool control cell.

| Part | Purpose | Approximate size (mm) |
| --- | --- | --- |
| [NFC agent badge](agents-of-howell-sneak-badge-nfc.stl) | Howell Sneak badge with the rear clips spaced apart to leave a flat area for an adhesive NFC tag. | 93 × 82 × 13 |
| [Standard agent badge](agents-of-howell-sneak-badge.stl) | Wearable badge for agents who will use a printed QR code or enter the activation code. | 93 × 82 × 13 |
| [Control box body, v2](howell-sneak-control-box-v2.stl) | Current box body for the prepared processor prop. | 174 × 114 × 81 |
| [Control box lid](howell-sneak-control-box-lid.stl) | Removable cover marked **Quantum Computer Controller**. | 175 × 118 × 8 |
| [Four-wire insert](howell-sneak-control-box-wire-insert.stl) | Decorative ribbon harness to display inside the control box when players open it. | 163 × 49 × 6 |

Import the STL files in millimeters. Keep the body, lid, and insert at the same scale. Preview the badge clips and raised details in your slicer, then print one of each part to check the fit before making copies.

## SNAVE Estates briefing

1. Open **Organizer access → Printable marker links** in the live game. Use the **An agent is born** link for mission activation. [Open the live scavenger hunt](https://superswiss.github.io/Treasuremap/)
2. For NFC badges, write that link to an adhesive NFC tag. Test the tag on a player’s phone, then attach it to the flat back between the clips and test it again. For standard badges, provide a printed QR code with the same link. The manual activation code is `HS-A1-4J7K`.
3. Hand out the badges at SNAVE Estates. Once the opening briefing is ready, have each team scan, tap, or enter the activation code on its game device.

## Pool control cell

1. Print the v2 body, lid, and wire insert. Set the body on a level surface. Dry-fit the insert with the wires visible, then check that the lid seats and lifts freely with its label facing up.
2. Stage the assembled box at the approved processor checkpoint, away from the water and pool equipment. Place a clearly visible colored indicator inside. Match its color to **What color is the prepared processor indicator?** in the guided organizer setup. The supplied configuration uses **Blue**.
3. After the pool sensor sweep, players open the box and submit the indicator color in **The rogue processor** mission. The correct answer activates cooling in the game. Re-scanning the Mega AI Chip marker shows **80°F**. Replace the indicator and lid before the next team arrives.

See the [setup checklist](../SETUP-CHECKLIST.md) for the full route and staging tasks.
